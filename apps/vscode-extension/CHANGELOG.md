# Changelog

## 0.2.0

- Always-visible right-side status-bar manager with rich workspace health.
- Separate recording and pending-review status indicator.
- Native Claude Code, Codex, and OpenCode session import workflow.
- Session discovery also supports Gemini CLI, VS Code Copilot Chat, Cline, and
  raw DeepSeek Harness logs across Windows, macOS, and Linux.
- Startup activation so the manager is visible without first opening the view.

## 0.1.0

- Native memory tree and status bar.
- Explicit remember, recall, explain, reinforce, decay, and project-context commands.
- Local-first transport over the stable LongMemory CLI JSON contract.
- Explicit AI change sessions for Copilot, Codex, Claude, Cursor, Windsurf, and
  other agents, including direct workspace file writes.
- Review-only opt-in heuristic candidates with honest attribution confidence.
- Compact bounded patches with sensitive-path filtering, credential redaction,
  in-memory baseline limits, and stable change metadata.
- Task-matched reusable Skills and validation steps in project context briefs.
- Governed four-asset loadouts resolved by configured agent/framework identity.
