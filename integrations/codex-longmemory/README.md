# LongMemory for Codex and ChatGPT

A native Codex plugin containing an LongMemory Agent Skill and bundled local stdio MCP configuration.

Prerequisite: install and initialize the `longmemory` CLI.

Add the repository or a local marketplace with `codex plugin marketplace add`, then install the `longmemory` plugin from the ChatGPT/Codex Plugins Directory. The manifest follows the current `.codex-plugin/plugin.json` layout.
