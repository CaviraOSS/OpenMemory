# LongMemory for Gemini CLI

A native Gemini CLI extension with local stdio MCP and session context.

Prerequisite: install and initialize the `longmemory` CLI.

```bash
gemini extensions link ./integrations/gemini-cli-longmemory
# or install a released copy
gemini extensions install ./integrations/gemini-cli-longmemory
```

Restart Gemini CLI after installing or updating the extension.
